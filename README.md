# Runefall

A puzzle game inspired by Dr. Mario where a shaman calms angry rising elements using magical runes.

## Game Concept

- **Shaman**: The player character who drops runes
- **Runes**: Falling pairs of colored squares (4 types: Fire, Water, Earth, Air)
- **Elements**: Rising angry circles that need to be calmed (4 types matching runes)
- **Goal**: Match 4 of the same type (rune + element combination) to make them disappear

## Controls

- **Arrow Left/Right**: Move rune pair horizontally
- **Arrow Up**: Rotate rune pair
- **Arrow Down**: Fast drop

## Current Implementation

- 4 element types (Fire, Water, Earth, Air)
- 4 rune types matching elements
- Basic grid system (8x16)
- Falling rune pairs
- Match-4 detection (horizontal and vertical)
- Simple colored shapes (squares for runes, circles for elements)
